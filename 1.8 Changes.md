# **-Pokémon TCG Generations- V1.8 by PaperFire88**

#### **Important Changes**:

* **New** **Type**! the **Metal** Type is added to the Game (Thanks **Mario Bone**!).
* **Supporters**! the mechanic is now present on Generations so now Trainers are Divided between Items and Supporters (Thanks **Oats!**)
* **New Weakness/Resistance system**, now depending on the Pokémon each Weakness and Resistance would have a value of (**+**/**-**) 10, 20 or 30.
* **New NPC's** from the sequel, which means more battles!!
* Now All Packs give **15** Cards! (1 Energy, 8 Commons, 4 Uncommons and 2 Rares.)
* Now All the cards in the collection can be used in **Multiple** Decks (Thanks **Oats**!).
* **New** In-Game modes, Different ways to play the game with different rules and restrictions.
* We now have TCG 2 portraits, so now the NPC's would should a Happy, Neutral or Sad look depending on the result of duel, it also implement expanded palette for them, just like the sequel (Thanks **Electro**!)
* Now all Poke Powers are called **Abilities.** (They work exactly the same, with the same conditions and limitations.)

#### **Minor Changes**:

* Added a new icon to the main duel screen, now you can see how many cards each player has in their hand.
* Added a new "**inherance**" system for certain cards, some cards can use their previous evo attacks (Thanks **Oats**!).
