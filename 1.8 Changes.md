# **-Pokémon TCG Generations- V1.8 by PaperFire88**

#### **Important Changes**:

* **New** **Type**! the **Metal** Type is added to the Game (Thanks **Mario Bone**!)
* **New Weakness/Resistance system**, now depending on the Pokémon each Weakness and Resistence would have a value of (**+**/**-**) 10, 20 or 30.





#### **Minor Changes**:

Added a new icon to the main duel screen, now you can see how many cards each player has in their hand.
